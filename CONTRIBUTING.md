# Contributing

Thanks for helping improve Locaith AI Agent.

## Before you start

- Found a bug or have an idea? Open an issue on GitHub. For a security problem follow [`SECURITY.md`](SECURITY.md) instead of opening an issue.
- For anything bigger than a small fix, open an issue first so we can agree on the approach before you spend time on it.

## Build and test

You need Node 20 or later.

```
cd extension
npm ci
npm run typecheck
npm test
npm run build:cli      # writes dist-cli/locaith.cjs, the terminal app
```

The tests for the Python package that ships the terminal app run with `python -m unittest discover -s packages/locaith-cli-py/tests`.

The Market skills inside the release packages are generated by `extension/scripts/build-market.mjs` from a separate skills collection and are not stored in this repository; a test that needs them skips itself when they are missing.

## Pull requests

- Keep a change focused, and add or update tests in `extension/test/`.
- User-visible text is kept in string tables in Vietnamese and English — change both languages.
- Run `npm run typecheck` and `npm test` before you push.
- Say what changed and why, and link the issue.
