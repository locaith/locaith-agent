# Locaith AI Agent for VS Code

Prebuilt distribution package for extension `LocaithAI.locaith-agent`, version `0.4.0`.

> This repository contains the supplied VSIX package, not the original editable source project or build scripts. It is a distribution repository rather than a source-code repository.

## Install

Download [`locaith-agent-0.4.0.vsix`](releases/locaith-agent-0.4.0.vsix), then install it in either way:

- In VS Code, open **Extensions** → **...** → **Install from VSIX...** and select the file.
- From a terminal, run `code --install-extension releases/locaith-agent-0.4.0.vsix`.

The package manifest declares VS Code engine `^1.90.0` and publisher `LocaithAI`.
